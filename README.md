PCA was applied to the standardized Optdigits dataset, which originally contained 64 numerical features. Based on the cumulative explained variance, 41 principal components were selected to retain approximately 95.06% of the total variance. Therefore, the dimensionality was reduced from 64 features to 41 components while preserving most of the information present in the original dataset. The first two principal components were used to visualize the reduced-dimensional data. The visualization shows that some digit classes form relatively distinct regions, while considerable overlap exists between several classes. This is expected because PCA focuses on preserving overall variance rather than directly maximizing class separation.
